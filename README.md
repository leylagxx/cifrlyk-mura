# Цифрлық мұра

«Цифрлық мұра» — Ұлытау өңірінің тарихы бойынша элективті курстың цифрлық платформасы (5–11 сыныптар, 34 сағат).
Цифровая платформа для авторской программы по истории Казахстана (история Ұлытау), конкурс «Үздік авторлық бағдарлама».

## Құрамы
- **Курс** — 6 бөлім, мәтін үш деңгейде: 5–6, 7–9, 10–11 сынып
- **Мұра картасы** — өңірдің 11 тарихи орны (схемалық карта)
- **Уақыт таспасы** — негізгі оқиғалар
- **Тапсырмалар** — автоматты тексерілетін тест және ашық тапсырма
- **Жобалар галереясы** және **Мұғалім кабинеті** (мысал деректер)

## Іске қосу
Бір ғана `index.html` файлы, жинақтау қажет емес. Браузерде ашыңыз немесе:

```bash
python3 -m http.server 8000
```

## Күйі
Прототип (MVP). Мәтіндер мен сұрақтар — мысал мазмұн, бағдарлама авторы тексереді.
Нәтижелер тек браузерде (localStorage) сақталады; сервер, ЖИ-көмекші және жоба жүктеу — екінші кезең.
